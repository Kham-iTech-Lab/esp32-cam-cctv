# ESP32-CAM CCTV — กล้องวงจรปิดราคาหลักร้อย

โค้ดประกอบคลิป **"กล้อง Wi-Fi ตัวจิ๋ว ราคาหลักร้อย ทำกล้องวงจรปิดเองได้"**
ติดตามได้ที่ TikTok **K iTech Review** · YouTube / Facebook **Kham iTech Lab**

เปิดภาพสดจากกล้องผ่านมือถือใน Wi-Fi บ้าน ถ่ายภาพนิ่ง เปิดไฟแฟลช และปรับความละเอียดได้จากหน้าเว็บ

## ของที่ต้องใช้

| ชิ้น | หมายเหตุ |
|---|---|
| ESP32-CAM (AI-Thinker) + กล้อง OV2640 | ส่วนใหญ่ขายมาพร้อมกล้อง |
| บอร์ด ESP32-CAM-MB **หรือ** USB-TTL | ใช้อัปโหลดโค้ด (MB เสียบ USB ได้เลย สะดวกกว่า) |
| ไฟเลี้ยง 5V 2A | ไฟไม่พอ = รีสตาร์ทเองบ่อย |

## วิธีอัปโหลด

1. ติดตั้ง Arduino IDE และ ESP32 board (Boards Manager → esp32 by Espressif)
2. เปิด `esp32_cam_cctv/esp32_cam_cctv.ino` แก้ `WIFI_SSID` กับ `WIFI_PASS`
3. Tools → Board → **AI Thinker ESP32-CAM**
4. อัปโหลด
   - **ใช้ ESP32-CAM-MB:** เสียบ USB เลือกพอร์ต แล้วกดอัปโหลดได้เลย
   - **ใช้ USB-TTL:** ต่อสายตามนี้ แล้ว **ต่อ IO0 ลง GND** และกด RESET ก่อนอัปโหลด

```
USB-TTL      ESP32-CAM
  5V    ->   5V
  GND   ->   GND
  TX    ->   U0R
  RX    ->   U0T
            IO0 -> GND   (เฉพาะตอนอัปโหลด)
```

5. อัปโหลดเสร็จ ถอดสาย IO0 ออก แล้วกด RESET
6. เปิด Serial Monitor (115200) จะเห็นเลข IP เช่น `http://192.168.1.60`
7. เปิด IP นั้นในมือถือ (ต้องต่อ Wi-Fi เดียวกัน) ก็จะเห็นภาพสด

## ใช้งาน

- **ถ่ายภาพ** ได้ไฟล์ .jpg ความละเอียดเดียวกับภาพสด
- **แฟลช** เปิด/ปิดไฟ LED ขาวบนบอร์ด (ร้อนเร็ว อย่าเปิดทิ้งไว้นาน)
- **กลับหัวภาพ** สำหรับติดกล้องคว่ำ
- **ความละเอียด** เลือกได้ตั้งแต่ 320x240 ถึง 1024x768

## ปัญหาที่เจอบ่อย

| อาการ | วิธีแก้ |
|---|---|
| `เปิดกล้องไม่สำเร็จ` | เช็กว่าเสียบสายแพกล้องแน่น ตัวล็อกปิดสนิท |
| รีสตาร์ทเองบ่อย / Brownout | ใช้ไฟ 5V 2A สายสั้น ๆ อย่าจ่ายจากขา 3.3V |
| อัปโหลดไม่เข้า | ลืมต่อ IO0 ลง GND หรือสลับ TX/RX ผิด |
| ภาพกระตุก | ลดความละเอียด หรือวางกล้องใกล้เราเตอร์ |

## หมายเหตุ

- ดูได้เฉพาะใน Wi-Fi บ้านเท่านั้น ไม่ได้เปิดออกอินเทอร์เน็ต ปลอดภัยกว่า
- ภาพสดเปิดดูได้ทีละ 1 เครื่อง
- ติดกล้องในบ้านหรือพื้นที่ของตัวเองเท่านั้น และไม่ถ่ายพื้นที่ส่วนตัวของคนอื่น
